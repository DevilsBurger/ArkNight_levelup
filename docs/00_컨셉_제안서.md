## 0. 한 줄 컨셉

> **"한 명은 압도적으로 강하다. 하지만 한 곳에만 설 수 있다."**
> 플레이어는 최약체에서 깨어난 헌터 **주인공**을 전장 위에서 직접 옮겨 가며 싸우고, 주인공이 **낙인**을 새겨 거둔 **군단원**을 명일방주 방식으로 타일에 **소집**해 게이트를 막는다.

### 0.1 피치 (30초)
- 명일방주의 전투 문법(타일 · 배치 코스트 · 저지 · 방향 · 스킬 · 3★)을 그대로 가져온다.
- 대신 "12명의 오퍼레이터를 지휘하는 박사" 자리에 **전장에 직접 서는 주인공**을 놓는다. 주인공은 코스트 0, 죽지 않고, 어떤 군단원보다 강하다.
- 강함의 대가는 **위치**다. 주인공은 한 타일에만 설 수 있고, 다른 길은 군단원이 막아야 한다. "주인공을 어디에 세우고 언제 옮기느냐"가 이 게임의 퍼즐이다.
- 군단원은 가챠가 아니라 **참전 시나리오**로 얻는다. 주인공이 구하거나 꺾은 자가 낙인을 받고 군단에 들어온다.
- 모든 것을 Synty SIMPLE 로우폴리로 그린다. 단순한 그림체 위에서 적 수십 마리가 쏟아지는 압도감을, 5년 된 폰에서도 60fps로 보여준다.

## 2. 핵심 판타지와 설계 기둥

### 2.1 플레이어 판타지
"나 혼자 다 쓸어버린다"는 쾌감과 "그런데 저쪽 길이 뚫린다"는 긴장을 한 스테이지 안에서 반복한다. 스테이지를 깨고 로비로 돌아오면 레벨이 올라 있고, 스탯을 찍고, 새 군단원이 늘어 있다.

### 2.2 설계 기둥 (우선순위 순)
| 기둥 | 규칙 |
| :--- | :--- |
| **P1. 한 명의 강함, 한 곳의 제약** | 주인공은 1:多에서 지지 않는다. 그러나 동시에 두 곳에 있을 수 없다. 모든 스테이지는 "주인공이 없는 길"을 하나 이상 만든다. |
| **P2. 명일방주 문법 유지** | 타일 · 코스트 · 저지 · 방향 · 스킬 · 3★. 명일방주 경험자는 설명 없이 플레이할 수 있어야 한다. |
| **P3. 성장이 보인다** | 매 세션 레벨업 · 스탯 · 새 군단원 중 하나는 반드시 생긴다. 헌터 등급 승급은 챕터 보스마다. |
| **P4. 가챠 없는 수집** | 군단원은 전부 플레이로 얻는다. 희귀도는 "얻기 어려운 시나리오"로 표현한다. |
| **P5. 단순한 그림, 선명한 정보** | Synty SIMPLE 실루엣 + 타일 데칼 + 색 코딩. 적 종류를 3초 안에 구분. |

## 3. 코어 게임플레이 (인게임)

### 3.1 코어 루프
```
[로비] 편성(주인공 + 군단원 8) → [게이트 진입] 주인공 배치(코스트 0)
   → 웨이브: 군단원 소집 · 주인공 재배치 · 스킬 · 권능
   → 클리어(★1~3) → XP · 재료 · (조건 충족 시) 참전 시나리오 해금
   → [로비] 레벨업 · 스탯 배분 · 군단원 성장 · 새 군단원 합류 → 다음 게이트
```

### 3.2 전장
- 타일 그리드 **13×8** 기본(16:9 랜드스케이프에 맞춤). 범위 11×7 ~ 15×9. 1타일 = 1 Unity 유닛.
- 타일 종류: 지상(근접 소집 · 저지) / 고지대(원거리 소집, 높이 0.5) / 배치 불가(건물 · 물 · 균열) / 출현 지점(붉은 균열) / 방어 지점(파란 결계) / 특수(함정 · 가속 · 치유).
- 적은 출현 지점 → 경로 → 방어 지점. 경로는 복수. 방어 지점 도달 시 생명 −1(초기 생명 3~10, 스테이지별).
- 카메라: 고정 탑다운, 피치 55° / 요 20°(고지대 높이가 읽히도록), 스테이지별 고정 프레이밍, 핀치 줌 없음.

### 3.3 주인공 (플레이어 유닛)
| 항목 | 규칙 |
| :--- | :--- |
| 등장 | 스테이지 시작 시 플레이어가 지상 타일 하나를 골라 배치. 코스트 0. 귀환 불가. |
| **재배치(핵심 조작)** | 주인공 카드 탭 → 이동 가능한 지상 타일 하이라이트 → 타일 탭 → **낙인 이동**(0.4s 연출, 즉시 도착). 쿨타임 8s(성장으로 5s까지). 이동 중 저지 해제. |
| 방향 | 가장 가까운 적을 자동으로 향한다(방향 선택 없음). |
| 저지 | 3(성장 시 5). 비행 적은 저지 불가. |
| 전투력 | 같은 레벨 군단원 대비 공격 약 2.5배, 체력 약 3배. 전방 부채꼴 범위 공격 기본. |
| **코스트 생산** | 적 처치 1마리당 DP +1(엘리트 +2, 보스 +5). 시간 회복은 명일방주의 70% 수준. → "적 많은 곳에 세워 경제를 돌릴지, 뚫리는 곳을 막을지" |
| 기세 | 처치마다 스택 +1(최대 10): 공격 · 공속 +3%/스택. 넉다운 시 0. "쓸수록 강해지는" 감각 |
| 권능 | SP는 **처치로만** 충전, 수동 발동, 스킬 트리에서 1개 장착(§4.1). 예: 일섬(직선 관통) / 총소집(군단원 재소집 대기 전부 초기화) / 지배(적 1체를 10s 아군화) |
| 넉다운 | HP 0 → "무릎 꿇음" 10s(저지 · 공격 · 재배치 불가) → HP 30%로 기립. 넉다운 중 적은 통과. 넉다운 1회 이상이면 **3★ 불가**. 패배는 오직 생명 0. |
| 제약 | 고지대에 설 수 없다. 봉인 타일(보스 구역 일부)에 들어갈 수 없다. 마법 저항이 높은 적에게 물리 대미지가 약하다 → 술사 군단원 필요. |

### 3.4 군단원 (소집 유닛)
- 명일방주 오퍼레이터와 동일 규칙: DP 코스트, 지상 / 고지대, 4방향, 저지 수, 사거리 타일, 스킬(SP 충전 유형 3종), 귀환(코스트 50% 환급) + 재소집 대기.
- 등장 연출: 타일 위 검은 낙인 원 → 유닛이 솟아오름(0.5s). 걸어 들어오지 않는다(연출 비용 절감 + 소환 판타지).
- HP 0 → **이탈**(강제 귀환, 재소집 대기 ×2). 영구 사망 없음.
- 편성: 주인공 + 군단원 **8명**(권장, D7). 한 손 조작 바에 8칸.

| 클래스 | 타일 | 역할 | 명일방주 대응 |
| :--- | :--- | :--- | :--- |
| 방패 | 지상 | 저지 3, 고방어 | 디펜더 |
| 창병 | 지상 | 저지 1~2, 고공격 | 가드 |
| 사수 | 고지대 | 단일 물리, 비행 우선 | 스나이퍼 |
| 술사 | 고지대 | 마법(방어 무시), 범위 | 캐스터 |
| 치유 | 고지대 | 회복(주인공 포함) | 메딕 |
| 지원 | 고지대 | 감속 · 약화 · 버프 | 서포터 |
| 특수 | 지상 / 고지대 | 빠른 재소집, 밀치기 · 당기기, 함정 | 스페셜리스트 |

선봉의 역할(DP 생산 · 초반 저지)은 주인공이 맡는다.

### 3.5 적
- 속성: HP · 공격 · 방어 · 마법저항 · 이동속도 · 중량 · 비행 여부(명일방주와 동일).
- 런칭 목표 **25종 + 보스 5종**. Synty SIMPLE은 몬스터 종류가 적으므로 **베이스 10종 × 변형(색 · 크기 · 머리 장식 · 무기)** 으로 확장하고, 변형은 머리 위 아이콘으로 구분한다(P5).
- 테마별 베이스(보유 패키지 기준, 프리팹 확정은 상세 설계에서): 고블린 · 스켈레톤(Simple Dungeons), 오크 · 기사 · 엘프(Simple Fantasy), 좀비(Simple Zombies), 군인 · 드론(Simple Military / Sky), 배신 헌터(Simple People), 골렘 · 석상(Simple Temple 소품 리깅).

### 3.6 스테이지 흐름과 평가
- 로비 편성 → 진입 → 주인공 배치 → 웨이브 → 클리어 / 패배 → 결과(XP · 재료 · ★).
- ★3 생명 무손실 + 넉다운 0 / ★2 생명 손실 있으나 1/3 이상 / ★1 클리어.
- 배속 1× / 2×, 일시정지, 연습 모드(보상 · 소모 없음), ★3 후 자동 지휘(리플레이).
- 목표 플레이타임: 일반 2~4분, 보스 4~6분.

## 4. 성장과 메타

### 4.1 주인공 레벨업
- 스테이지 클리어 XP → 레벨(챕터마다 상한 해제, 런칭 Lv.60).
- 레벨당 스탯 포인트 3. 스탯 5종: **힘**(공격) / **체력**(HP) / **방어** / **민첩**(공속 · 재배치 쿨) / **지휘**(처치 DP · 군단원 버프). 무료 리셋(로비에서만).
- 스킬 트리 3갈래: **무쌍**(개인 화력 · 범위) / **군주**(경제 · 군단 버프 · 총소집) / **불굴**(넉다운 단축 · 자가 회복 · 저지 +). 권능은 각 갈래 끝에 1개.
- 헌터 등급 E→D→C→B→A→S: 챕터 보스 클리어마다 승급. 수치가 아니라 **서사와 외형**(코트 · 무기 교체 · NPC 대사)이 바뀐다.
- 장비: 무기 · 방어구 · 장신구 3슬롯. 게이트 드랍 · 제작. 가챠 아님.
- 일일 수련: 일퀘 3개(처치 n · 스테이지 n · 재배치 n) → XP · 재료.

### 4.2 군단원 성장
- 레벨 / 각성 단계 0→1→2(사거리 · 스킬 추가, 외형 변화) / 스킬 랭크 1~7 / 유대(로비 대사 · 소량 스탯).
- 재료는 자원 게이트와 메인 스테이지 드랍.

### 4.3 군단원 획득: 참전 시나리오
- 모든 군단원은 **참전 시나리오**를 클리어하면 합류한다. 주인공이 그를 구하거나(헌터 · 민간인) 꺾어서(몬스터) 낙인을 새긴다.
- 종류:
  - **메인 합류**: 챕터 진행 중 자동 해금(챕터당 1~2명). 누구나 얻는다.
  - **숨은 합류**: 메인 스테이지에서 특정 조건(특정 적을 주인공이 직접 처치, 민간인 생존 등)을 만족하면 해금. 탐색 보상.
  - **이벤트 합류**: 기간 한정 시나리오. 종료 후 "회상"으로 재도전 가능(영구 미획득 없음).
- 희귀도 ★3~6은 가챠 확률이 아니라 **시나리오 난이도 · 조건**으로 표현한다.
- 런칭 로스터 목표 24명(메인 10 · 숨은 10 · 이벤트 4). 역할 예시:

## 5. 세계관과 시나리오 골격

### 5.1 세계
- 현대 도시. 12년 전부터 **게이트**(공간 균열)가 열리고 안쪽에 던전이 생긴다. 방치하면 **게이트 붕괴** → 몬스터가 도시로 쏟아진다.
- 게이트에 들어가 싸울 수 있는 각성자 = **헌터**. 협회가 등급(E~S)을 매기고 길드가 레이드를 조직한다.
- 몬스터는 게이트 너머의 세계에서 온다. 후반 챕터에서 "너머"의 주인들이 드러난다.

### 5.2 주인공
- 20대 E급 헌터. 가족 병원비 때문에 레이드 짐꾼 노릇. 이름은 플레이어 입력(기본값 제공).
- 1장 사건에서 **낙인**을 받는다. 낙인은 정체불명의 존재가 새긴 계약이며 시스템 창으로 말을 건다(= 게임 UI). 낙인은 레벨업을 허락하고, 주인공이 거둔 자를 소집하게 한다.
- 성격: 말수 적고 실용적. 군단원이 떠들고 주인공은 짧게 답한다(대사량 절감).
