## 2. BM 후보 비교

| 후보 | 장점 | 단점 | 적합도 |
| :--- | :--- | :--- | :---: |
| A. 프리미엄(유료 다운로드) | 광고 · 상점 없음 | 신규 IP 모바일 유료 전환율 극히 낮음, 라이브 운영 동기 약함 | ★ |
| B. 캐릭터 가챠(명일방주형) | 검증된 ARPU, 수집 동기 | **P4 · D3와 정면 충돌**. 참전 시나리오라는 차별점을 버린다 | ★ |
| C. 장비 가챠 하이브리드 (00 D3 대안) | 캐릭터는 플레이로, 장비는 가챠 | 장비가 ATK · HP를 바꾸는 순간 "성장 재화 판매 금지"가 무너진다. 시뮬레이션(08 §4)에서 군단 능력치 ±20%가 ★3율을 60%p 흔든다 — 장비 가챠는 곧 난이도 가챠 | ★★ |
| D. F2P 광고 중심(하이퍼캐주얼) | 설치 장벽 0 | 미드코어 세션에 전면 광고는 이탈 요인, eCPM 의존 | ★ |
| E. **F2P 외형 + 시즌 패스 + 편의 + 선택형 광고** | 설계 기둥과 충돌 없음, 다층 수익, 6주 시즌 운영과 호환 | ARPU 상한이 낮다. 스킨 제작 파이프라인 · 운영 리소스 필요 | **★★★★★** |
| F. 구독 | 안정 매출 | 단독으로는 가치 설득 어려움 | ★★ (E의 보조) |

**선정: E + F(보조).** 수익은 "스킨(수집) : 시즌 패스(반복) : 편의(시간) : 광고(보조)" 네 층이고, 어느 층도 전투 결과를 사지 못한다.

### 2.1 U5 — 장비의 런칭 포함 여부
- **포함한다.** 장비는 GDD §5.11대로 게이트 드랍 · 제작이며 판매 · 가챠 · 강화권 상품이 없다. BM에 영향이 없으므로 "런칭 범위 결정"은 개발 일정(10 TDD §11 마일스톤) 문제로 돌린다.
- 장비 재료의 자원 게이트(재료 T3~4)는 일 3회 제한이 있다 → 편의 상품 "추가 입장"의 대상이지만 **일 +2회 상한**(§4.3).

### 2.2 D3 — 하이브리드(장비 가챠) 보류 조건
- 소프트런칭 8주 시점에 **ARPDAU < 목표(§7)의 60%** 이고 **D30 ≥ 목표**(즉 "재미는 있는데 돈이 안 된다")일 때만 시즌 3 안건으로 올린다.
- 올리더라도 범위는 "외형 · 편의에 확률 요소"(예: 스킨 상자)까지이며 **능력치가 붙은 장비 가챠는 어떤 조건에서도 넣지 않는다**(08 §4의 민감도가 근거).

## 3. 재화 설계

GDD §10.5의 재화 6종을 BM 관점에서 다시 적는다. 젬만 과금과 닿는다.

| 재화 | 종류 | 획득 | 소비 | BM 관계 |
| :--- | :--- | :--- | :--- | :--- |
| 골드 | 소프트 | 스테이지 · 자원 게이트 · 의뢰 · 일일 수련 | 모든 성장 비용 | 판매 없음. 광고 "보상 ×1.5"로만 간접 |
| 기록 결정 · 재료 T1~4 · 스킬 서 | 소프트(성장) | 스테이지 드랍 · 자원 게이트 · 제작 · 주간 과제 | 군단원 레벨 · 각성 · 스킬 · 장비 | 판매 없음. 자원 게이트 추가 입장(편의)만 |
| 명성 | 소프트(경쟁) | 무한 게이트 · 주간 과제 · 도전 모드 | **명성 상점**: 재료 · 일반 스킨 조각 · 편성 프리셋 | 판매 없음. 무과금의 스킨 경로 |
| 스킨 조각 | 수집 | 명성 상점 · 패스 무료 트랙 · 7일 출석 · 챕터 ★ 상자 | 일반 스킨 완성(조각 10) | 무료 스킨 경로. 젬으로 조각을 살 수 없다 |
| 젬 | 하드 | 첫 ★3 · 도전 첫 클리어 · 참전 시나리오 · 업적 · 주간 · **IAP** | 스킨 · 편의 · 회상 패스 · 패스 등급 · 프리미엄 트랙 | 유일한 과금 접점 |
| 낙인 토큰(신규) | 시즌 | 시즌 패스 등급 · 이벤트 | 시즌 한정 스킨 · 낙인 연출 교환 | 시즌 종료 시 젬 1:10 환전(소멸 없음) |

원칙:
1. 젬 → 성장 재화 환전 **없음**(GDD §10.5). 젬 → 골드 교환 상품도 두지 않는다(RUN BEANIE와 다른 점 — 그쪽은 성장이 없어 골드 교환이 무해했다).
2. 모든 스킨은 **젬 없이도** 도달 가능한 경로가 하나는 있다(일반: 조각, 프리미엄: 시즌 패스 프리미엄 트랙 환급 젬 300으로 1시즌에 1개).
3. 재화는 전부 서버 정산(UGS Cloud Save + 영수증 검증, 10 TDD §8). 오프라인 획득분은 접속 시 합산.

## 4. 수익원 상세

### 4.1 스킨 (수집 축)

| 구분 | 대상 | 획득 | 내용 | 런칭 수 |
| :--- | :--- | :--- | :--- | :-: |
| 일반 | 군단원 24 · 주인공 | 조각 10(명성 상점 · 패스 무료 트랙 · 상자) | 의상 · 팔레트 변경. 모델 재활용 | 10 (주인공 1 + 군단원 9) |
| 프리미엄 | 주인공 · 메인 합류 10 | 젬 300(군단원) · 600(주인공) | 의상 + 이펙트(공격 궤적 · 스킬 색) · 주인공은 **권능 연출 · 재배치 궤적 · 낙인 연출**까지 | 5 (주인공 2 + 군단원 3) |
| 시즌 한정 | 주인공 1 + 군단원 1 | 시즌 패스 프리미엄 트랙 · 낙인 토큰 | 시즌 테마(1시즌 = "하수도 군주의 유산" 등 챕터 테마) | 2 / 시즌 |
| 챕터 번들 | 챕터 테마 스킨 | 보스 클리어 시 1회 팝업 $2.99(+ 젬 200) | 성취 순간 전환 상품 | 5 |

- 스킨은 **100% 외형**. 사거리 · 이펙트 범위 · 피격 판정이 바뀌어 보이면 안 된다(06 §6 적 식별 원칙과 같은 이유로 **적 스킨은 없다**).
- Synty SIMPLE 모듈러 의상 + 팔레트로 일반 스킨 1종 ≈ 0.5인일, 프리미엄(이펙트 포함) ≈ 2인일. 시즌당 신규 4~5종이 운영 상한.
- 주인공 등급(GDD §5.10)이 오르면 기본 외형이 바뀐다 — 이것은 **무료**이고 스킨은 그 위에 덧씌운다.

### 4.2 시즌 패스 ("낙인 패스") — 반복 축

| 항목 | 내용 |
| :--- | :--- |
| 기간 | **6주** = 이벤트 2개(03 §10: 3주 이벤트 = 군단원 1~2 + 참전 시나리오 + 신규 기믹 1) |
| 등급 | 40. 패스 XP = 일일 수련 3(각 20) · 주간 과제(각 60) · 메인 · 참전 첫 ★3(30) · 무한 게이트 주간 결산(웨이브당 2) · 이벤트 스테이지(20) |
| 페이스 | 일일 + 주간만으로 5주차에 40등급 도달(일 60 + 주 120 ≈ 주 540 XP, 등급당 70). 결제자가 "다 못 깨는" 패스는 만들지 않는다 |
| 무료 트랙 | 골드 · 재료 T1~3 · 스킬 서 · 스킨 조각 10(= 일반 스킨 1) · 젬 100 · 낙인 토큰 10 |
| 프리미엄($4.99) | 젬 환급 300(= 가격의 60%) · 시즌 한정 스킨 2 · 낙인 연출 1 · 소탕권 20 · 의뢰 슬롯 +1(시즌 중) · 낙인 토큰 40 |
| 번들($9.99) | 프리미엄 + 10등급 즉시 |
| 등급 구매 | 젬 50/등급, **마지막 주에만** 노출 |

- 패스 XP는 **난이도 선택과 무관**해야 한다 — 도전 모드 ★는 XP를 더 주지 않는다(초보가 패스 때문에 도전 모드를 강요받지 않게).
- 패스 보상에 **성장 재화가 있지만** 자원 게이트 1주 분량 이하로 묶는다(무료 트랙 기준). 프리미엄 트랙은 성장 재화를 더 주지 않는다 — 차이는 외형 · 젬 · 편의뿐.

### 4.3 편의 (시간 축) — 상한이 있는 상품

| 상품 | 가격 | 상한 | 설계 의도 |
| :--- | :--- | :--- | :--- |
| 소탕권 | 젬 10/장, 패스 · 월정액 지급 | ★3 스테이지만. 자동 지휘(★3 해금, GDD §8.6)의 "건너뛰기" 버전 | 반복 파밍의 시간 절약. 미★3 스테이지는 불가 → 실력 대체 아님 |
| 자원 게이트 추가 입장 | 젬 50/회 | **일 +2회**(기본 3회 → 최대 5회) | 성장 속도 상한 ≤ 1.7배. 그 이상은 어떤 상품으로도 불가 |
| 의뢰 즉시 완료 | 젬 30(4h) · 50(8h) · 70(12h) | 일 2회 | 협회 의뢰(GDD §10.4)의 시간 단축 |
| 편성 프리셋 +4 | 젬 100(영구) | 1회 | 순수 편의 |
| 회상 패스 | §4.4 | 이벤트당 1회 | 조기 개방 |

- "자동 지휘 가속"(00 §8 후보)은 **팔지 않는다**. 2배속과 자동 지휘는 무료(★3 조건)이며, 유료로 더 빠르게 하는 상품은 결정론 재생의 검증 부담만 늘린다.
- 재도전 · 부활 · 전투 중 DP 구매 같은 **전투 안 상품은 없다**. 전투 결과는 입력 로그만으로 재현돼야 하고(GDD §8.6), 돈이 결과에 들어가는 순간 랭킹 · 리플레이의 신뢰가 깨진다.

### 4.4 회상 패스 — 이벤트 참전 시나리오 조기 개방

- 이벤트 참전 시나리오(런칭 4종, 시즌당 2종 추가)는 종료 후 "기록 → 회상"에서 **복각 주기(약 3개월)** 에 다시 열린다(GDD §10.2). 회상 패스(젬 300 또는 $2.99)는 그 복각을 **기다리지 않고 즉시** 여는 권리다.
- 군단원은 여전히 시나리오를 **직접 클리어해야** 합류한다(P4). 구매가 주는 건 시간뿐이다. 신규 · 복귀 유저가 "지난 군단원을 못 얻는" 불만의 출구이기도 하다.
- 진행 중인 이벤트는 회상 패스 대상이 아니다. 종료 후 30일 뒤부터 구매 가능(FOMO 상품이 되지 않도록).

## 8. UX 보호 원칙 (BM이 넘지 말아야 할 선)

1. 스테이지 입장에 **어떤 재화도 요구하지 않는다**. 자원 게이트 일 3회만 예외이고, 그 추가분도 상한이 있다.
2. **전투 안에 상품이 없다**: 부활 · 재도전 보너스 · DP 구매 · 광고 보상 없음. 전투는 입력 로그만으로 재현된다.
3. 젬 → 성장 재화 환전 없음. 성장 속도 상한 1.7배(자원 게이트 +2).
4. 광고는 로비 · 결과 창에서만, 보상형만, 같은 크기의 "건너뛰기". 결제자는 광고 없이 같은 보상.
5. 스킨은 외형만. 적 · 타일 · 사거리 표시를 바꾸는 외형은 팔지 않는다(06 §6 식별 원칙).
6. 보스 스테이지 직전 · 직후 팝업은 챕터 번들 1회뿐. 컷씬 중 팝업 없음.
7. 패스 XP는 난이도 선택과 무관. "다 못 깨는 패스"를 만들지 않는다(5주차 완주).
8. 기간 한정 군단원은 회상에서 복각된다. 회상 패스는 시간을 팔지 희소성을 팔지 않는다.
9. 연령: KR 12세 / ESRB T / PEGI 12. 13세 미만 가능성 대비 연령 게이트 + 광고 SDK 아동 플래그 + 개인화 광고 기본 OFF. 확률형 상품이 없으므로 확률 공시 의무는 없다 — 스킨 상자 같은 확률 상품을 넣는 순간 §2.2 조건과 함께 재검토.
